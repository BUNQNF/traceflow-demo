## 已冻结项目事实

- **目标用户：** 产品经理主导需求协同；业务方、UI 设计师、前端工程师与验收方参与固定角色视图。
- **核心情境：** 2027 新年头像工坊 H5 在 `v1.0` 已完成 `REQ-001` 至 `REQ-009` 后，运营方新增“主题模板自定义色彩变体”，推动形成 `v1.1`。
- **业务关联：** `需求版本 -> 原型页面/交互 -> UI 页面/组件 -> 前端模块/预览 -> 验收用例/发布包`。
- **真实性边界：** 内置示例数据；AI 分析与外部设计、代码产物均为可解释模拟；演示状态和版本记录在浏览器本地保存。
- **明确排除：** 用户/组织/角色配置、真实 Figma 或 Git 同步、真实代码生成部署、多人实时编辑和外部通知接入。
- **视觉约束：** 桌面优先的企业后台工作台；浅色中性底、左侧导航、顶栏、紧凑表格与状态视图。移动端用于查看、审核和验收等轻量操作。不得复制 BMS 品牌标识或菜单内容。
